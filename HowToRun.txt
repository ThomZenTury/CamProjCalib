
To duplicate conda env:
    # on the PC running the current environment, copy the env specs to a yml file
        conda env export > spec-file.yml    # stored in the current folder your terminal is in

    # on another PC where you want to install the same environment, create the conda env with the spec.yml file
        conda env create -f spec-file.yml
